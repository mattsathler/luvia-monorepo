# Filosofia de Código

## Objetivo

Definir os valores centrais que orientam decisões técnicas.

## Decisões consolidadas

### Código

Sempre preferir clareza ao invés de esperteza. Código simples é melhor que código inteligente.

### Componentes

Componentes devem possuir responsabilidade única. Preferir pequenos componentes. Evitar componentes acima de ~300 linhas.
