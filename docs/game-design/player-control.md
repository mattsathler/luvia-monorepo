# Controle do Jogador

## Objetivo

Definir o que o jogador controla e o que é simulado pelo sistema.

## Decisões consolidadas

O jogador controla apenas decisões. Exemplos:

- Trabalhar
- Estudar
- Descansar
- Dormir
- Ir para um evento
- Fazer compras
- Encontrar amigos

Ele NÃO controla:

- Movimento
- Combate
- Caminhar
- Animações

### Sem combate

Luvia não possui:

- HP
- Mana
- Armas
- Classes
- PvP
- Dungeons
- Bosses

Nunca sugerir sistemas inspirados em MMORPGs tradicionais de combate.
