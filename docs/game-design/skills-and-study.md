# Estudos e Habilidades

## Objetivo

Definir como o jogador desenvolve habilidades.

## Decisões consolidadas

O jogador pode estudar. Estudar aumenta habilidades.

Habilidades permitem:

- melhores empregos
- promoções
- abrir empresas
- produzir melhor

Nunca existem classes.
