# Chat e Interações Sociais

## Objetivo

Definir como jogadores interagem entre si.

## Decisões consolidadas

Não existe chat em tempo real.

Nunca sugerir chat global. Nunca sugerir chat privado.

Interações devem ocorrer por ações do jogo.
