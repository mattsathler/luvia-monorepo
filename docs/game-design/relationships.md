# Relacionamentos

## Objetivo

Definir o sistema de relacionamentos entre jogadores.

## Decisões consolidadas

Relacionamentos são um dos pilares do jogo.

Existem níveis como:

- conhecido
- amigo
- melhor amigo
- namoro
- casamento

Relacionamentos influenciam diversas mecânicas.
