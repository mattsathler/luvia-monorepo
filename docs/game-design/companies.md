# Empresas

## Objetivo

Definir como funcionam as empresas de jogadores.

## Decisões consolidadas

Empresas pertencem aos jogadores.

Tipos:

- Comércio
- Indústria

Empresas:

- contratam jogadores
- compram materiais
- vendem produtos
- administram contratos
