# Economia

## Objetivo

Definir o papel da cidade na regulação da economia.

## Decisões consolidadas

Existe uma cidade controlada pelo sistema. Ela representa consumidores.

A cidade:

- compra produtos
- vende produtos
- gera empregos públicos

Ela regula a economia.
