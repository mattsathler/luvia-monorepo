# Sistema Industrial

## Objetivo

Definir o fluxo de produção da economia.

## Decisões consolidadas

A indústria produz matéria-prima. O comércio transforma. Depois vende para a cidade.

Fluxo:

```text
Indústria → Comércio → Cidade
```
