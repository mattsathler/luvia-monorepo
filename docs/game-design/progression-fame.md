# Progressão e Fama

## Objetivo

Definir o sistema de progressão do jogador.

## Decisões consolidadas

O jogo utiliza **Fama** como principal indicador de progresso.

Não existe Level. Nunca utilizar "Level" em interfaces — sempre utilizar "Fama".
