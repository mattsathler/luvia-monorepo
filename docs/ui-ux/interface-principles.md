# Princípios de Interface

## Objetivo

Definir os princípios que toda interface do jogo deve seguir.

## Decisões consolidadas

A interface deve ser:

- limpa
- minimalista
- cozy
- confortável
- com poucos elementos simultâneos

Nunca criar interfaces poluídas.
