# Plano — Responsividade e acessibilidade

## Status

⏳ Pendente

## Objetivo técnico

O design system (`luv-ui`) já tem convenções de responsividade e acessibilidade nos componentes isolados — este plano é revisar as TELAS reais do jogo (composições inteiras), onde problema costuma aparecer mesmo com componentes individualmente corretos.

## Escopo

- Revisão de cada tela de jogo (dashboard, cidade, empresa, relacionamentos, criação de personagem) em mobile e desktop.
- Revisão de labels, contraste e navegação por teclado nas telas principais do fluxo de jogo (login → personagem → dashboard → cidade).

## Onde no código

- `apps/game/src/pages/`

## Depende de

- Todas as telas de jogo das milestones anteriores já existirem.
