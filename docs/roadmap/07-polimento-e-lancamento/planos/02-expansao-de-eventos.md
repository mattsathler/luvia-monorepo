# Plano — Expansão de eventos

## Status

⏳ Pendente

## Objetivo técnico

A M04 fechou com 2 tipos de evento pra validar o mecanismo — aqui o catálogo cresce pro tamanho que o game design sempre previu (ver [[../../../game-design/events]]: festa, congresso, feira, festival, evento sazonal).

## Escopo

- Adicionar os tipos de evento que faltaram na M04.
- Pelo menos 1 evento sazonal/recorrente, testando o caso de disponibilidade não-trivial (M04, plano 01, deixou essa regra genérica).

## Onde no código

- `apps/api/src/character/domain/entities/activity.ts` (ou onde evento acabou modelado na M04)

## Depende de

- Catálogo de eventos (M04, plano 01).
