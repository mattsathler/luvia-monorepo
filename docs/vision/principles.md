# Princípios de Design

## Objetivo

Definir os princípios que toda decisão de design do jogo deve seguir.

## Decisões consolidadas

### Cozy First

Luvia deve ser confortável. Nada deve gerar ansiedade. Não existem punições severas. Não existe FOMO. O jogador pode voltar horas depois sem sentir que perdeu tudo.

### Idle First

O jogo não é controlado em tempo real. O jogador escolhe uma atividade, o personagem executa, e o tempo passa sozinho.

### Social First

Toda mecânica deve incentivar interação entre jogadores. Mesmo sistemas econômicos devem existir para conectar pessoas. Nunca criar mecânicas totalmente isoladas.

### Long Term Progression

Luvia deve durar anos. Todo progresso deve ser lento. Nada deve ser facilmente maximizado.

## Observações

Sempre que uma nova funcionalidade for proposta, ela deve ser verificada contra estes quatro princípios. Se qualquer princípio for violado, a proposta deve ser rejeitada.
