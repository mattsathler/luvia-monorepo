# Luvia — Game

Aplicação principal do jogo Luvia (React + TypeScript + Vite), consumindo os componentes do design system [`luv-ui`](../../packages/luv-ui).

## Scripts

Rodar a partir da raiz do monorepo:

```bash
npm run dev          # inicia o dev server do jogo
npm run build:game   # build de produção
```

Ou dentro desta pasta: `npm run dev`, `npm run build`, `npm run preview`, `npm run typecheck`.
