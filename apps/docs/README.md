# Luvia — Docs (storybook do luv-ui)

Aplicação interna para visualizar e testar os componentes do design system [`luv-ui`](../../packages/luv-ui). Não é publicada nem exposta publicamente — funciona como um storybook simples dentro do monorepo.

## Scripts

Rodar a partir da raiz do monorepo:

```bash
npm run dev:docs     # inicia o dev server do storybook
npm run build:docs   # build de produção
```

Ou dentro desta pasta: `npm run dev`, `npm run build`, `npm run preview`, `npm run typecheck`.
